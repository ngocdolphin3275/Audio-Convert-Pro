Audio Convert Pro 2.3.1

A focused Windows desktop audio converter with a compact queue, batch processing,
format-aware encoding options, progress reporting and FFprobe verification.

Supported output formats
- MP3
- FLAC
- AAC
- WAV
- OGG/Vorbis
- M4A/AAC
- ALAC

Portable use
1. Download and extract the complete ZIP package.
2. Open the extracted folder.
3. Run AudioConvertPro.exe.
4. Keep the application folder and its _internal directory together.

The package includes the application, Python runtime, CustomTkinter, TkinterDnD2,
the required Tcl/Tk runtime files, FFmpeg and FFprobe. No separate Python,
FFmpeg or dependency installation is needed.
